02 — Approach

I build interfaces as instruments.

Motion is not decoration. It is how a system explains itself — hierarchy, cause, consequence.

Depth over flatness. Restraint over spectacle. Every layer deliberate.

The result should read as software crafted several years ahead of its moment.

03 — Systems

What I engineer

  • Production front-ends where the interaction model is the product. Type-safe, framework-honest, tuned to the frame budget — no jank, no layout thrash, no hover-only affordances.

  • Choreography with intent — cinematic transitions, purposeful parallax, cursor physics. Reduced-motion is first-class, never an afterthought bolted on at the end.

  • Fragment shaders and generative fields that stay ambient, not loud — depth, light, and grain composed to sit behind an interface without ever competing with it.

  • Reusable primitives that compound — OKLCH token systems, honest contrast, keyboard paths that actually work. Systems so the next idea is faster than the last.
